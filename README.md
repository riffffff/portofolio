# Simple Modern Portfolio (React + Vite)

Mobile-first, minimal, and interactive portfolio built with React + TypeScript + Vite.

## Features
- Clean hero with animated avatar accent
- Sections: About, Projects, Contact
- Subtle hover/press micro-interactions
- Dark/light theme via CSS variables
- Fully responsive with mobile-first grid

## Quick Start

```powershell
npm install
npm run dev
```
Open the local URL printed by Vite (usually `http://localhost:5173`).

## Customize
- Edit text in `src/App.tsx` (titles, descriptions, links)
- Tweak colors/spacing in `src/index.css` variables
- Add project cards in the `#projects` section

## Build
```powershell
npm run build
```
Outputs production files into `dist/`.
